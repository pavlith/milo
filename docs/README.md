# Milo platform documentation

Milo is a universal, extensible Linux-first desktop platform. The native host and the Workbench are implemented through Stage 02. The roadmap records verification and identifies the remaining Core MVP work. See the root README for prerequisites and commands. [Roadmap](ROADMAP.md) · [Root README](../README.md)

- [Vision](VISION.md) defines the product, terminology and MVP scope.
- [Architecture](ARCHITECTURE.md) describes the current runtime and the target boundaries between Go, Wails and Svelte.
- [Workbench](WORKBENCH.md) describes the seven regions, tabs and UI contributions.
- [Modules](MODULES.md) defines the seven trusted services, including Task.
- [Extensions](EXTENSIONS.md) defines the planned SDK, lifecycle, trust boundary and packaging.
- [Codex guide](CODEX.md) describes how to implement and verify a stage.
